>
> **▶ Slide 27 · Démo 2 · Une à la souris, une en commande.**

Fichiers ajoutés : `scoring/score.py` (la fonction `add_predictions` + un `main` qui lit un CSV et écrit un CSV), `data/customers.csv`, et `policies/list-buckets.json` écrite à l'étape 1.

## Sur « mon laptop » (le runner) : ça marche

```bash
python scoring/score.py data/customers.csv /tmp/out.csv && cat /tmp/out.csv
```

## À la souris

Console Floci → **Compute** → bouton **Launch instance**.

- Instance name : `clic`
- AMI : `al2023-ami-2023.0.20230315.0-kernel-6.1-x86_64` (Amazon Linux 2023)
- Instance type : `t3.micro`
- Key pair : `None`
- **Launch**

L'instance passe en `running`. On montre son ID, son image, son type. Elle sert juste à voir à quoi ressemble « louer une machine ».

## La même chose en commande, avec une clé pour y entrer

```bash
# Une clé SSH pour la machine
aws ec2 create-key-pair --key-name ml-key --query KeyMaterial --output text > ml-key.pem
chmod 400 ml-key.pem

# Je loue une machine
ID=$(aws ec2 run-instances --image-id ami-amazonlinux2023 --instance-type t3.micro \
      --key-name ml-key --query 'Instances[0].InstanceId' --output text)
echo $ID

aws ec2 describe-instances --instance-ids $ID \
  --query 'Reservations[0].Instances[0].[State.Name,PrivateIpAddress]' --output text

aws ec2 describe-instances --query 'Reservations[].Instances[].[InstanceId,State.Name]' --output table
# les deux instances : celle du clic et celle de la commande
```

Console → **Compute** → **Refresh** : les deux instances côte à côte. On termine celle du clic avec l'icône poubelle de sa ligne (*Terminate*).

L'API EC2 ne renvoie pas d'ARN pour une instance. On le construit au tableau : `arn:aws:ec2:us-east-1:000000000000:instance/<ID>`.

## Entrer dans la machine

> **▶ Slide 28 · Démo 2 · Entrer dans la machine.**

Floci installe le serveur SSH au démarrage de l'instance : compter **30 à 40 s** après `run-instances` avant le premier `ssh` (le temps de commenter la slide 26 suffit). Si `ssh` répond `Connection refused`, attendre 10 s et relancer.

```bash
IP=$(aws ec2 describe-instances --instance-ids $ID \
      --query 'Reservations[0].Instances[0].PrivateIpAddress' --output text)
scp -i ml-key.pem scoring/score.py data/customers.csv root@$IP:
ssh -i ml-key.pem root@$IP
```

Sur la machine :

```bash
python3 score.py customers.csv out.csv && cat out.csv
exit
```

## La chute

> Après la chute, slides 29 et 30, puis la pause (slide 31).

```bash
aws ec2 terminate-instances --instance-ids $ID
```

`out.csv` a disparu avec la machine, et elle était facturée chaque seconde même quand personne ne s'en servait. Deux problèmes, deux réponses dans les étapes suivantes.

> Floci : l'instance est un conteneur Docker, `PrivateIpAddress` est son adresse sur le réseau `floci_default`, que le runner partage. Sur AWS, on passerait par l'IP publique ou un bastion.
